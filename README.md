# homebrew-type4me

Homebrew tap for [Type4Me](https://github.com/joewongjc/type4me) — macOS voice input tool.

## Install

    brew tap joewongjc/type4me
    brew trust joewongjc/type4me
    brew install --cask type4me

## Upgrade

    brew upgrade --cask type4me

## Uninstall

    brew uninstall --cask type4me
